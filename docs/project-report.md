# Multi-Cluster eBPF Security, L7 API Protection & Live SOAR Automation

## 1. Project Overview

This project aims to design, implement and evaluate a multi-cluster Kubernetes security environment using Cilium eBPF networking, Cilium ClusterMesh, WireGuard encryption, Layer 7 API policies, Hubble network observability, Suricata intrusion detection and Python-based Security Orchestration, Automation and Response (SOAR).

The environment will contain two Kubernetes clusters, named `cluster-east` and `cluster-west`. The project will evaluate secure cross-cluster communication, API access restrictions, network visibility and automated responses to selected security alerts.

## 2. Objectives

1. Deploy two local Kubernetes clusters.
2. Establish cross-cluster connectivity using Cilium ClusterMesh.
3. Configure and verify WireGuard encryption.
4. Implement and test Layer 7 API security policies.
5. Collect network-flow evidence using Hubble.
6. Integrate Suricata alerts with a Python-based automated response mechanism.
7. Measure the response time and network performance.
8. Document the architecture, implementation, test results and limitations.
