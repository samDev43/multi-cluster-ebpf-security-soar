# Advanced eBPF Kubernetes Security and Automated SOAR

## Project Overview

This project demonstrates the implementation of cloud-native security monitoring and automated incident response in a Kubernetes environment using Cilium, eBPF, Cilium Tetragon, Suricata, WireGuard, Hubble, and Python-based SOAR automation.

The project combines two major security implementations:

1. **Multi-Cluster Network Security:** Securing communication between Kubernetes clusters using Cilium, WireGuard, Hubble, network policies, Suricata, and automated firewall response.
2. **Runtime Security and Automated Pod Quarantine:** Monitoring kernel-level activities using Cilium Tetragon and eBPF, detecting suspicious behaviour, collecting forensic evidence, and automatically isolating affected Kubernetes pods.

The objective is to demonstrate how network security, runtime monitoring, and automated incident response can work together to improve Kubernetes security.

## Project Implementations

### Part 1: Multi-Cluster eBPF Network Security

#### 1. Multi-Cluster Kubernetes

Configured East and West Kubernetes environments and connected them using Cilium ClusterMesh.

#### 2. WireGuard Encryption

Enabled WireGuard encryption to protect communication between the connected Kubernetes clusters.

#### 3. Network Microsegmentation

Implemented Cilium network policies to control communication between selected workloads.

#### 4. L7 API Protection

Implemented and tested HTTP-based network policies to permit authorized requests and restrict unauthorized API operations.

#### 5. Network Observability

Used Hubble to observe network communication and monitor traffic flows across the Kubernetes environment.

#### 6. Suricata Intrusion Detection

Configured custom Suricata detection rules and verified the detection of HTTP traffic from a simulated attacker.

#### 7. Network-Level SOAR Automation

Developed a Python automation script to process Suricata alerts and update an nftables firewall set to block simulated attackers.

### Part 2: eBPF Runtime Security and Automated Pod Quarantine

#### 1. Tetragon Deployment

Deployed Cilium Tetragon 1.8.0 alongside the Cilium Kubernetes networking environment to monitor kernel-level activities.

#### 2. Custom Runtime Monitoring Policies

Developed custom Tetragon TracingPolicies to monitor:

- Suspicious shell and process execution.
- Access to sensitive files.
- Selected Linux capability usage.

#### 3. Python SOAR Event Processing

Developed a Python-based SOAR processor that receives and analyses JSON security events generated by Tetragon.

The processor classifies events by severity and determines the appropriate response.

#### 4. Forensic Evidence Collection

Implemented JSON evidence collection to preserve details of detected security events for investigation.

#### 5. Automated Pod Quarantine

Integrated the SOAR processor with Kubernetes and CiliumNetworkPolicy.

When a HIGH-severity event is detected, the automation applies a quarantine policy targeting the affected pod.

#### 6. Duplicate Response Prevention

Implemented duplicate-response suppression to prevent repeated quarantine actions for the same target during a running SOAR session.

## Architecture Overview

The project uses two complementary security workflows.

**Network Security Workflow:**

Suricata detects suspicious network traffic, Python processes the alert, and the SOAR automation updates the nftables firewall set.

**Runtime Security Workflow:**

Tetragon observes kernel-level activities, generates security events, Python processes the events, forensic evidence is collected, and HIGH-severity events trigger automated Kubernetes pod quarantine through CiliumNetworkPolicy.
